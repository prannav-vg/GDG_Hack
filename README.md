# ShadowData 
**Privacy & Permission Abuse Detection Android App**

ShadowData is an Android application designed to help users **understand, monitor, and control how installed apps access sensitive device resources** such as the camera, microphone, location, and contacts.  
It focuses on **real-time privacy awareness**, **explainability**, and **on-device intelligence**.

---

##  Key Features

###  Real-Time Privacy Monitoring
- Detects live access to **camera** and **microphone**
- Displays current privacy status on the dashboard
- Instantly alerts users when sensitive resources are accessed

---

###  Privacy Mode (Women Safety Mode)
- Locks camera and microphone access
- Detects and alerts on any unauthorized access attempts
- Designed for proactive privacy protection

---

###  AI-Based Risk Prediction
- Uses **on-device AI** to classify apps as:
  - SAFE
  - SUSPICIOUS
  - DANGEROUS
- No cloud usage — all predictions run locally

---

###  Permission Explainability
- Converts technical permission names into **simple human-readable explanations**
- Helps non-technical users understand privacy risks clearly

---

###  Installed App Analysis
- Lists installed apps with risk indicators
- Provides detailed permission breakdown per app
- Highlights over-permissioned applications

---

###  Alerts & Incident Logging
- Logs all high-risk privacy events
- Maintains a timeline of incidents
- Supports **CSV and PDF export** for reports and evaluation

---

###  Multi-Theme Support
- Light Theme  
- Dark Theme  
- Green (Security) Theme  
- Themes dynamically affect background, cards, text, and controls

---

###  Privacy-First Design
- No audio, video, or personal data is recorded
- No data is sent to external servers
- Entirely offline and on-device processing

---

##  App Screens

- **Main Dashboard** – Live privacy overview and controls  
- **App List** – Installed apps with risk analysis  
- **App Detail** – Permission breakdown and risk explanation  
- **Alerts & Incidents** – Privacy violation logs and exports  
- **Settings** – Theme selection and preferences  
- **About** – Project overview and privacy principles  

---

##  Tech Stack

- **Language:** Kotlin  
- **UI:** Jetpack Compose (Material 3)  
- **Architecture:** Single-Activity, Modular Composables  
- **AI / ML:** TensorFlow Lite (On-device inference)  
- **Navigation:** Jetpack Navigation Component  

---

##  Google AI Tools Used

- **TensorFlow Lite**
- **On-device Machine Learning (Edge AI)**

---

##  Project Objective

ShadowData aims to:
- Improve user awareness of permission misuse
- Provide explainable privacy insights
- Demonstrate responsible, privacy-preserving AI on mobile devices

---

##  Disclaimer

ShadowData is a **research and educational project**.  
It does not bypass Android security policies or collect personal user data.
